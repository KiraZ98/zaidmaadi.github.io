Project 01 · Operations Research · 2025

Capacitated Vehicle Routing Solver (CVRP)

Completed
C++ MILP SCIP Floyd–Warshall
Challenge
Plan the cheapest set of delivery routes for a fleet serving multiple customers, where each vehicle has a fixed capacity and each stop a known demand — the textbook last-mile cost driver.
Method
Formulated the CVRP as a Mixed-Integer Linear Program with capacity, flow-conservation, and subtour-elimination constraints. Pre-computed the shortest-path distance matrix using Floyd–Warshall, then drove the SCIP solver from a C++ pipeline that reads instances, builds the model, and exports the routes.
Impact
Returns a provably cost-optimal route assignment for benchmark instances and exposes total distance, vehicles used, and load per route — directly translatable to fleet sizing and route-cost benchmarking for a logistics operator.

Project 02 · Network Planning · Ongoing

Public Transport Route Network Design

In progress
GAMS Linear Programming Network Flow
Challenge
Design a public transport line plan that minimizes operating cost while covering the demand on every origin–destination pair in the network.
Method
Linear programming + network flow formulation in GAMS. Decision variables: line selection and frequency. Constraints: passenger flow conservation, demand coverage on each OD pair, and fleet budget.
Impact
Outputs a cost-minimizing line plan for the input demand graph; sensitivity runs isolate the corridors that drive the most cost — the basis for service-level trade-off decisions.

Project 03 · Applied ML · Ongoing

Bike Availability Forecasting — Vienna Nextbike

In progress
Python Jupyter Time-Series 8 mo. ops data
Challenge
Predict station-level bike availability across Vienna's Nextbike network so the operator can reposition vehicles before empty-dock or full-dock events block trips.
Method
Cleaned and aggregated 8 months of station-level operational data in Python. Engineered temporal features (hour of day, weekday, holiday), weather signals, and station-neighbourhood structure; trained predictive models per station class in Jupyter.
Impact
Forecasts feed a fleet rebalancing plan — turning availability uncertainty into a scheduling input rather than an after-the-fact KPI.

Project 04 · Spatial Economics · 2025

Road Pricing Policy — CGE Modelling

Completed
GAMS CGE Welfare Analysis
Challenge
Quantify the economic effect of road pricing across two regions and decide whether a publicly run scheme or a private operator delivers the better outcome.
Method
Built a two-region Computable General Equilibrium model in GAMS — calibrated production, consumption, and a price-elastic transport demand block. Ran counterfactual scenarios for each governance mode and compared welfare outcomes.
Impact
Identifies the scheme with the lower welfare loss per €1 of revenue raised, and exposes the regional distributional effects — a clean basis for a defensible policy recommendation.

Project 05 · Transport Policy · 2025

Mode Choice Modelling — Multinomial Logit

Completed
R Apollo Discrete Choice MNL
Challenge
Explain how travellers pick between competing transport modes given travel time, cost, and individual attributes — and turn that into a tool for evaluating policy.
Method
Estimated a Multinomial Logit model in R using the Apollo discrete-choice package. Tested specifications with alternative-specific constants and interaction terms; validated significance and model fit.
Impact
Coefficients quantify how strongly each modal attribute shifts choice probability — the model then simulates how pricing or service changes would shift modal split.
